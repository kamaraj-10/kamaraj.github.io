Session 5: Retrieval Mechanisms

Finding the Right Information Fast

What are Retrieval Mechanisms?

Retrieval mechanisms are the strategies and techniques used to find relevant information from a document store when a user asks a question. The better your retrieval mechanism, the better your RAG system performs.

Key Principle: If you retrieve the wrong documents, even the best language model can't generate a good response. Retrieval is the foundation of RAG success!

Types of Retrieval Mechanisms

1. Keyword-Based Retrieval

The simplest approach: search for documents that contain the keywords from the question. Like using Ctrl+F to find text in a document.

Pros:

  • Fast and simple
  • Works well for exact matches
  • Easy to implement

Cons:

  • Doesn't understand meaning
  • Fails with synonyms
  • Poor for complex questions
Example:
Question: "How do I fix my computer?"
Keyword search: "computer" "fix"
Result: Only finds documents with these exact words

2. Semantic Search / Vector-Based Retrieval

Uses embeddings to understand meaning. Finds documents that are semantically similar to the question, even if they don't use the exact same words.

Pros:

  • Understands meaning
  • Works with synonyms
  • Great for complex queries

Cons:

  • Computationally expensive
  • Quality depends on embedding model
  • May return irrelevant documents
Example:
Question: "How do I fix my computer?"
Semantic search finds documents about:
- Troubleshooting
- PC problems
- System repairs
Even if they don't use "fix" or "computer"!

3. Hybrid Retrieval

Combines keyword and semantic search. Uses both approaches and merges results intelligently.

Approach:

  1. Get keyword search results
  2. Get semantic search results
  3. Merge and rank them
  4. Return best results

Advantages:

  • Combines strengths of both approaches
  • Better overall performance
  • More robust to edge cases

4. Query Expansion

Improves retrieval by automatically expanding the user's question with related terms or reformulations.

Original Query: "laptop warranty"

Expanded Queries:
- "laptop warranty period"
- "computer warranty coverage"
- "device protection plan"
- "hardware warranty terms"

Results from all expanded queries are combined!

5. Multi-Hop Retrieval

For complex questions that require information from multiple documents, multi-hop retrieval retrieves relevant information in multiple steps.

Example:
Question: "What's the warranty on laptops bought from the discount section?"

Step 1: Find documents about discount products
Step 2: From those, find warranty information
Step 3: Combine information from both steps

Retrieval Quality Metrics

Precision

What percentage of retrieved documents are actually relevant?

Retrieved 10 documents, 7 are relevant = 70% precision

Recall

What percentage of all relevant documents were retrieved?

10 relevant documents exist, retrieved 7 = 70% recall

Advanced Retrieval Techniques

Re-ranking

Retrieve many candidates (e.g., top 100), then use a more sophisticated model to re-rank them and return the best few. This improves quality while staying fast.

Filtering

Pre-filter documents by metadata (date, category, source) before semantic search to reduce scope and improve speed.

Caching

Store results for common questions and return cached results instead of retrieving again. Speeds up common queries significantly.

Practical Tips for Better Retrieval

  • Document Chunking: Break documents into appropriate sizes - too small loses context, too large loses precision
  • Metadata: Include rich metadata (title, author, date, category) to enable better filtering
  • Testing: Evaluate your retriever on real questions users ask
  • Iterating: Use metrics to identify and fix retrieval failures
  • Balancing: Balance between precision and recall based on your use case

Key Takeaways

  • Retrieval is critical - garbage in, garbage out
  • Keyword-based retrieval is simple but limited
  • Semantic/vector-based retrieval understands meaning better
  • Hybrid retrieval combines both approaches for better results
  • Query expansion can improve retrieval for complex questions
  • Multi-hop retrieval handles questions requiring information from multiple sources
  • Always measure and optimize retrieval quality
