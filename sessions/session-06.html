Session 6: Prompt Engineering for RAG

Crafting Better Prompts for Better Responses

What is Prompt Engineering?

Prompt engineering is the art and science of writing instructions that guide an AI model to produce the desired output. In RAG systems, the prompt tells the generator how to use retrieved documents to answer the user's question.

Key Insight: The same retrieved documents can produce very different responses depending on how you prompt the generator. Good prompts are crucial for RAG success!

Basic Prompt Structure for RAG

Simple RAG Prompt:

"Using the following documents, answer the question: [QUESTION]

Documents:
[RETRIEVED_DOCUMENTS]

Answer: "

Key Elements of a Good RAG Prompt

1. Clear Instructions

Tell the model exactly what you want it to do.

Weak: "Answer this question"

Better: "Using only the provided documents, provide a clear and concise answer to the following question"

2. Context and Role

Define the model's role and context.

"You are a helpful customer service representative. Using the company's knowledge base below, answer the customer's question..."

3. Document Presentation

Present retrieved documents clearly.

Good Format:

Document 1: [source]
[content]

Document 2: [source]
[content]

4. Output Format Specification

Specify exactly how you want the answer formatted.

"Provide your answer in 2-3 sentences. If the documents don't contain enough information, say so."

5. Source Attribution

Ask the model to cite its sources.

"Please cite the document or section you used for each fact."

Advanced Prompt Techniques

Chain-of-Thought Prompting

Ask the model to show its reasoning step by step.

"Let's think through this step by step:
1. What information from the documents is relevant?
2. How does it answer the question?
3. Is there any conflicting information?
Based on this analysis, provide your answer."

Few-Shot Prompting

Provide examples of the desired output format.

Example 1:
Q: "What's your return policy?"
A: "Based on our policy documentation, items can be returned within 30 days of purchase..."

Now answer this:
Q: [USER_QUESTION]

Conditioning on Document Quality

Include instructions for when retrieved documents might be insufficient.

"If the provided documents don't contain relevant information, respond with: 'I don't have enough information to answer this question. Please contact support.'"

Common Prompt Mistakes

Mistake 1: Ambiguous Instructions

Bad: "Answer the question"
Better: "Using only the provided documents, give a concise 1-2 sentence answer"

Mistake 2: Poor Document Formatting

If documents are presented unclearly, the model can't use them effectively.

Mistake 3: Trusting Hallucinations

Forgetting to instruct the model to stick to the documents.

Mistake 4: Over-Complicated Prompts

Simpler prompts often work better than overly complex ones.

Best Practices

1. Be Specific

  • Specify desired length (e.g., "in 1-2 sentences")
  • Specify tone (e.g., "professional", "friendly")
  • Specify format (e.g., "bullet points", "paragraph")

2. Test and Iterate

  • Try different prompt variations
  • Measure which works best on test questions
  • Keep improving based on results

3. Handle Edge Cases

  • What if no relevant documents are found?
  • What if documents conflict?
  • What if the question is outside the knowledge base?

4. Transparency

  • Ask model to cite sources
  • Request confidence levels
  • Ask for alternatives if possible

Example: Customer Support RAG Prompt

Full Prompt:

"You are a friendly and helpful customer service representative. Using ONLY the knowledge base provided below, answer the customer's question concisely and accurately. If the knowledge base doesn't contain the information needed to answer, politely explain that and suggest they contact support. Always cite which document section you used for your answer.

KNOWLEDGE BASE:
[DOCUMENTS]

CUSTOMER QUESTION:
[QUESTION]

RESPONSE:"

Key Takeaways

  • Prompt engineering significantly impacts RAG quality
  • Good prompts are clear, specific, and well-structured
  • Document formatting in the prompt matters
  • Always instruct the model to stick to provided documents
  • Ask for source attribution to improve transparency
  • Test and iterate on prompts based on real performance
  • Use advanced techniques like chain-of-thought for complex tasks
